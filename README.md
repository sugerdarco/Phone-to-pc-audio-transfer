# PhoneToPC Audio (Android 15)
A real-time audio streaming app for Android 15 to Windows 11 over UDP.

## Build via GitHub Actions
1. Push this repository to GitHub.
2. Go to the **Actions** tab in your GitHub repository.
3. Select the **Build Android APK** workflow and click **Run workflow**.
4. Once completed, download the signed or debug APK from the artifacts section.
